# Implementation Plan: Stage 3 — Multi-Model Staged Reranking & 3x3 Factorial Grid

===============================================================================
1. STAGE 3 OBJECTIVES & SCOPE
===============================================================================

Stage 3 completes Phase 1 of the experimental design by scoring all 3 candidate sets generated in Stage 2 (BM25, Dense bge-base, RRF Hybrid) through two modern reranker champions:
  1. `BAAI/bge-reranker-v2-m3` (Cross-Encoder champion)
  2. `BAAI/bge-reranker-v2-gemma` (Decoder/LLM-based reranker champion, 2.5B parameters)

Key Deliverables:
- 6 Reranked Runs: Rerank the top-50 candidates for all 300 test queries across 3 candidate sets x 2 rerankers.
- Staged GPU Memory Management: Enforce strict single-model VRAM residency (T4 16GB ceiling). Load m3, score all arms, unload from VRAM; then load gemma (fp16 or 4-bit fallback), score all arms, unload.
- Complete 3x3 Factorial Grid (9 cells): Evaluate Recall@10, MRR, nDCG@10, P@1, and total end-to-end query latency for all 9 cells.
- Quality-vs-Latency Pareto Frontier Selection: Construct the Pareto curve, identify dominated configurations, and select the top 2-3 survivor configurations to advance to Phase 2 (Generation & Faithfulness).

===============================================================================
2. RERANKER MODELS & STAGED GPU ARCHITECTURE
===============================================================================

Model 1: `BAAI/bge-reranker-v2-m3`
- Type: Cross-Encoder (sequence classification).
- Size / VRAM: ~1.1 GiB (fp16 on CUDA with SDPA attention).
- Scoring: Computes similarity logits for (query, doc_text) pairs in batch.

Model 2: `BAAI/bge-reranker-v2-gemma`
- Type: Decoder-based / LLM reranker (2.5B parameters).
- Size / VRAM: ~5.0 GiB (fp16 on CUDA). If VRAM tight, fallback to 4-bit quantization via `bitsandbytes` (`load_in_4bit=True`).
- Scoring: Causal LLM logit extraction for query-document relevance.

Memory Residency Policy (Non-Negotiable §3):
- Only ONE model resident in VRAM at any time.
- After m3 finishes all 3 candidate sets, `del model`, `torch.cuda.empty_cache()`, `gc.collect()` before instantiating gemma.
- Persistent disk storage: Every run is saved to `artifacts/runs/` immediately upon completion so session timeouts never lose work.

===============================================================================
4. STEP-BY-STEP IMPLEMENTATION PLAN
===============================================================================

Step 1: Reranker Wrappers Module (`src/rerankers.py`)
- Implement `M3Reranker` class wrapping `FlagEmbedding.FlagReranker` or `transformers.AutoModelForSequenceClassification` with batching and fp16 SDPA support.
- Implement `GemmaReranker` class wrapping `FlagEmbedding.FlagLLMReranker` or `transformers.AutoModelForCausalLM` with optional 4-bit bitsandbytes fallback.
- Standardize interface: `rerank_candidates(query_text, candidate_docs) -> List[Tuple[doc_id, score, text]]`.

Step 2: Staged Reranking Pipeline (`src/03_rerank.py`)
- Load Stage 2 candidate runs (`retrieval_bm25.json`, `retrieval_dense.json`, `retrieval_rrf.json`) and document texts.
- **Stage 3A (m3 Reranking):** Load `bge-v2-m3`, rerank all 3 candidate sets, measure per-query rerank latency, evaluate metrics, save `rerank_m3_*.json` files. Unload m3 from GPU VRAM.
- **Stage 3B (gemma Reranking):** Load `bge-v2-gemma`, rerank all 3 candidate sets, measure per-query rerank latency, evaluate metrics, save `rerank_gemma_*.json` files. Unload gemma from GPU VRAM.
- Assemble full 3x3 Factorial Grid matrix (9 cells).
- Compute Pareto Frontier (nDCG@10 vs Total Query Latency ms), identify non-dominated knee configurations, and output `stage3_rerank_metrics.json`.

Step 3: Verification Script (`src/verify_stage3.py`)
- Cold reload all 9 run JSONs and `stage3_rerank_metrics.json` from `artifacts/runs/`.
- Validate candidate structure (300 test queries, 50 candidates/query, docids resolve).
- Cross-validate metrics against `pytrec_eval`.
- Render the complete **3x3 Factorial Grid Table (9 cells)**.
- Report Pareto Frontier Ranking & list top 2-3 survivor configurations.
