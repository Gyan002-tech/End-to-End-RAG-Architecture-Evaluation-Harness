# Difference from requirements.txt: torch is NOT listed. Colab ships a torch
# build compiled against its own CUDA driver; replacing it with a PyPI wheel is
# the single most common way to break a T4 session. env_check.py verifies the
# preinstalled torch satisfies the constraints (CUDA available, sm_75, fp16).
#
# Install order matters — numpy is pinned first, then everything resolves
# against it. After BOTH parts finish you MUST do Runtime -> Restart session
# (numpy is already imported by Colab at startup, so the downgrade only takes
# effect after a restart). Re-run env_check.py after restarting.
#
# Every pin below was checked against PyPI metadata: the version exists, and
# its declared constraints are mutually satisfiable under numpy 1.26.4.
